# Mesures de sécurité
Ce document est avant tout un guide de bonnes mesures à destination du développeur pour rendre le produit stable. Aucun des point mentionné ci-dessous n'est un engagement définitif.
## Stockage des données
Le stockage des données est réglementée par le RGPD. Il faut absolument rentrer dans la norme dès le partage de cette application.
